# leadledger-web

Skickar besökare från [leadledger.se](https://leadledger.se) vidare till [www.leadledger.se](https://www.leadledger.se), där webbplatsen ligger i AWS (ADR 0119). Hostad med GitHub Pages från `main`, eftersom one.com inte vidarebefordrar huvuddomänen utan ett betalt tillägg.

`index.html` och `404.html` är samma sida, så att också gamla länkar till undersidor hamnar rätt, med samma sökväg.
